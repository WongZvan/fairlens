# ADR：成品视图改为单页翻页（真实分页）

> 状态：**方向定案（2026-11-24，用户提出；预览待过目）**。决策总账 #131。业务代码未开始。
> 关联：docs/01 §5.1 库页 · §5.2 画布与权限矩阵 · §9 导出 · §14 测试；m1.7 导入 · m5.1 导出。
> 用户原话要点：导入后一次显示一张 A4，提供 `‹ 上一页　1 / 3　下一页 ›`，可缩放查看；有解析疑点就标在对应页并允许直接跳转；所有文字照常导入，页数按当前模板实际排版计算，编辑或切模板后更新；**不增加逐页强制确认步骤**；原文件页数与重新排版后的成品页数分开标明。**不要按固定高度把长画布硬切，也不要只加两个没有真实分页能力的箭头。**

## 1. 背景

- 当前编辑器是**可向下延伸的长纸面**，只有近似分页线；导出 PDF 由 WebView2 `PrintToPdf` 按 CSS 分页，屏幕与成品并不严格同页。
- 导入后需要判断“这简历能不能投、有多长”，长纸面 + 近似分页线无法回答。
- m1.7 导入的产品路径已定：解析清楚直接打开、疑点才检查；成品视图应接在“导入并打开”之后。

## 2. 决策

### 2.1 成品视图 = 单页翻页（默认）

- 编辑器默认显示**一张 A4**，`‹ 上一页 / N / 下一页 ›` 翻页；支持缩放（50–150%，默认按窗口高度适配，一次完整看到一页）。
- **不增加逐页强制确认**：翻页是查看/编辑导航，不是导入确认步骤。
- 疑点（导入遗留的未归类/低置信）标在**对应页的纸外挂标**（页边/页脚），点击跳到该页并高亮；标记属于屏幕 chrome，**不进入成品导出**。
- 顶部固定显示 `原文件 2 页 → 排版后 3 页`，两种页数分开标明，不暗示还原原版式。

### 2.2 真实分页，不用固定高度硬切

- 分页输入 = **当前模板的实际排版结果**（字体/字号/行高/页边距/分区规则/密度）；按渲染后的块高度测量并分配，不按固定像素切片。
- 规则：
  - **分区标题与后续首个内容同页**（避免标题落单）；放不下则标题整体移到下一页。
  - **条目可在要点边界跨页**；同一自动生成的续页小标题（`机构 · 职位（续）`）出现在续页顶部；**单条要点不跨页拆分**。
  - 超长单块（高于一页）需单独策略（缩小/截断提示/允许溢出），验收前定案。
  - 分页是文档属性，不是视图状态：同一 doc + 模板 + 密度 → 固定页数，屏幕与导出共用。
- 编辑（改要点/加条目/删条目）、切换模板、切换密度 → **重新分页**；分页失败不得丢内容。

### 2.3 屏幕与 PDF 同源

- 导出的 PDF 页数与分页断点必须与屏幕一致；导出时隐藏翻页 chrome、疑点挂标、缩放与提示。
- 不得出现“屏幕 3 页、PDF 4 页且断点不同”而不提示；如 PDF 引擎仍有差异，必须在导出前显示“成品页数可能变化”并要求确认（临时兜底，最终目标是同源）。

### 2.4 范围与顺序

- 新增模块 **m1.9 成品分页视图**；顺序暂定 `m1.7 → m1.9 → M1 收口`（最终顺序在预览过目时确认）。
- 当前长纸面是过渡实现；m1.9 落地后作为成品视图替换。是否保留“连续长纸面”调试模式**未定**（默认不保留，避免两套视图口径）。
- 本轮只交付**可点击预览 + 验收方案**，不写业务代码；预览过目后才进入真实分页实现。

## 3. 否决方案

| 方案 | 否决理由 |
|---|---|
| 按固定高度切长画布 | 与模板排版脱节，条目/标题会被拦腰截断；屏幕与 PDF 无法同源 |
| 只加两个箭头、不实现分页 | 用户看到的是“假翻页”，无法回答简历几页、是否跨页 |
| 逐页强制确认导入 | 把整理成本前置；用户主路径仍是“导入→打开→检查疑点” |
| 还原原文件版式 | 导入是转换到 FairLens 模板的可编辑内容；原版式还原属另一能力 |
| 屏幕分页与 PDF 各自计算 | 两套口径必然漂移；验收无法判定“所见即所得” |

## 4. 验收锚点

`acceptance/M1.md §16`：单页翻页/缩放、页数计算、条目跨页与续页小标题、标题不落单、编辑/模板/密度重排、疑点标记与跳转、原文件页数 vs 排版页数、屏幕=PDF、性能。
