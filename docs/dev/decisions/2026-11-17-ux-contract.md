# ADR：UIUX 交互契约轮（#127）

> 决策编号：总账 #127
> 日期：2026-11-17
> 状态：已实施（用户四轮拍板：范围 / 关闭契约 / 未完成能力呈现 / 示例处置 / 条目入口 / 空白点击 / Ctrl+K / 保存失败模型）
> 背景：用户要求「以 ZCode 为参照但不照搬，拷打当前阶段 UIUX 与交互逻辑，逐项讨论并给依据」

## 1. 审计结论（不是审美问题）

三份只读审计 + 复核，按伤害排序：

| 级别 | 事实 | 根因 |
|---|---|---|
| P0 | 新增分区里打的字重开即丢 | `flSection` content 不允许直属 `flBullet`，`insertSection` 却插 bullet；`sectionOf` 也不收集 |
| P0 | 行首 Backspace 删掉页头/条目头 | 两者是 atom，无自定义 Backspace，PM `joinBackward` 直接删前置 atom；profile 随之消失 |
| P0 | 保存失败仍 toast「已保存」 | `autosave.flush()` 失败只置 error 不抛；三处调用无条件报成功 |
| P0 | 保存失败后关窗不拦截 | `resolveGuardMode` 只看 autosave/dirty/issues |
| P0 | 无法新增/删除条目 | 全仓只有分区/字段命令，没有 `insertEntry/deleteEntry` |
| P0 | 点空白只认「最后一条要点下方」 | `pickAppendTarget` 语义过窄，空分区/行间/条目间全无反应 |
| P1 | 五个浮层五种退出行为，两处 Esc/点外都不响应 | 缺统一浮层基座 |
| P1 | 关闭浮层后焦点落 body | 全仓无 returnFocus |
| P1 | 全局快捷键在输入框里乱触发 | 只判 `inEditor`，不判 `input/textarea/overlay` |
| P1 | 评估面板硬编码 62 分/glm-4.7/死 CTA | 打样假数据无标注 |
| P1 | 画布常驻假分页「技能证书 → 第 2 页」 | 示例遗留 |
| P1 | 菜单徽标是里程碑编号 | 开发语言进入用户界面 |
| P1 | 搜索条盖住右栏 | 按 `.editor-mock` 右缘定位而非画布列 |

## 2. 三条规则（R1–R3）

- **R1 浮层契约**：非破坏性浮层 = 点遮罩关 + Esc 关（IME 守卫）+ 关闭后焦点归还 + 焦点陷阱；破坏性确认（CloseGuard）只能点按钮，Esc=取消，点遮罩不关。实现=`app/Overlay.tsx`。
- **R2 键盘契约**：同一键不承担两种语义；输入框/浮层内不触发全局快捷键；每个快捷键都能在「视图 → 快捷键速查（`?`）」查到。
- **R3 不做假按钮**：未实现能力 = 空态 + 人话说明；不出现可点无反应的按钮，不出现里程碑编号。

## 3. 关键改动

- **结构性**：`insertSection` 改为插空 flEntry；新增 `insertEntry/deleteEntry/duplicateEntry` 命令；分区标题 hover「添加条目」；条目头「⋯」复制/删除；右键菜单补删除条目；命令面板补结构命令；大纲显示空条目；分区标题清空后写回「未命名分区」。
- **数据安全**：`AtomGuard` 扩展拦结构锚点的 Backspace/Delete（纯函数 `shouldBlockAtomDeletion` + 7 单测）；`autosave.flush()` 返回 `{ok,pending}`，`saveNow()` 返回 `{ok}`，只在成功时 toast；状态栏失败态可点重试；CloseGuard 新增 `save-error` 模式（重试保存并关闭 / 仍然关闭 / 取消），关闭失败不放行。
- **空白点击全量**：`pickClickTarget`（纯函数 + 9 单测）返回 append-bullet / insert-bullet / insert-entry；纸面灰区不响应（不往错误分区插）。
- **关闭/焦点**：`Overlay` 基座迁移设置/命令面板/快照/关闭保护/元信息/分区/页头字段；SearchBar 例外（工具面板不点外关，但 Esc 全局可关 + 焦点归还）；Dropdown 统一接管菜单/模板/导出下拉。
- **去假象**：评估面板改空态；删除假分页标记；菜单徽标改「未开放」+ 人话 tooltip（**修订 #124⑥**）；状态栏 Ctrl+K 提示仅编辑器显示且去里程碑号；简历库文案去「打样」；右栏默认关闭并持久化开合；照片槽点击给明确说明。
- **示例**：`SAMPLE_RESUME_TITLE` 识别系统示例 → 画布顶部横幅 + 「清空为空白简历」；清空前自动存快照；清空后记录改名「我的简历」。
- **其他**：Ctrl+K 恒为命令面板，链接编辑改 Ctrl+Shift+K；Toast 不再挡点击、时长按字数、1s 同文去重；页头字段框补 Enter；删除分区改用应用内确认；导出下拉补「另存为归档」（父项 id 改 `file.export`）；视图菜单按真实缩放档位打勾；粘贴气泡 4s→8s。

## 4. 契约变更

`Entry.org` 由 `min(1)` 改为 `min(1).optional()`：新建条目在用户填写机构名之前必须能保存（否则"新增条目"一点就写库失败）。序列化时空串不落库；UI 用「机构名称」占位；`doc-projection` 的 `ProjectedEntry.org` 同步可选。消费方（大纲、投影、diff）本就按空值兜底。

## 5. 被否决的方案

- **Ribbon 式多行工具栏**（#124 已否决，本轮沿用）。
- **只隐藏未实现能力**：用户不知道 AI 存在、不知道为什么导出少格式 → 采用"空态 + 人话"。
- **删除条目弹二次确认**：结构删除可 Ctrl+Z 撤销，确认框反而增加阻力 → 直接删 + toast 提示可撤销。
- **点空白在纸面灰区也插条目**：会把内容插进错误分区，改为不响应。
- **保存失败自动重试**：多一层定时器与错误去重，收益不足；本轮做显式重试。

## 6. 已知限制 / 遗留

1. **真窗待人工**：960×640 下结构编辑、关闭契约、保存失败拦截需真机点（浏览器已程序化验证 325 测试 + 关键路径）。
2. **禁止项迁移未完成**：命令面板/悬浮工具条的标题与 aria 文案仍有硬编码中文（下一轮 i18n 清理；canvas-menu 已迁）。
3. **不做**（用户确认不在本轮）：m1.8 简历库/首启三选一/模板选择、AI 真实现、照片上传、键盘拖拽排序、Word 等导出、命令面板全局化。
4. **Overlay 叠层**：多个浮层同时打开时 Esc 会依次关闭（无栈管理）；当前唯一入口不会叠开（浮层打开时快捷键被守卫）。
