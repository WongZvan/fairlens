> **用途**：STATE「待人工验收」每一条的操作路径与判定标准。自动化（单测/浏览器冒烟/CDP）已覆盖的部分不在此列——这里只放**必须真机点一遍**的项。
> **规则**：每条四段——**前提 / 步骤 / 判定 / 取证**。判定写「看到什么算 PASS」，避免"看起来对"式验收。
> **文案事实源**：所有按钮/提示文字均取自 `apps/desktop/src/i18n/locales/zh-CN.ts`。若界面文字与此处不一致，**以代码为准并回报漂移**（说明手册或实现有一方错了）。
> **回填**：验完把结果告我（例「1、3、5 过，第 2 条 FAIL：点取消后窗口关了」）→ 我同步更新本文件勾选框 + STATE 待验收节。

## 1. IME 真机（最高风险：误触=误删/误改）

**前提**：真窗已启动并进入编辑器；系统输入法切到**微软拼音**（或任一中文输入法）。

**步骤**
1. 点进任一要点末尾。
2. 输入 `nihao`，**不要按空格选字**，直接按 `Enter`。
3. 再输入 `ceshi`，组合态未上屏时按 `Ctrl+S`。
4. 再输入 `shishi`，组合态未上屏时按 `Ctrl+D`。

**判定（全部满足才 PASS）**
- 第 2 步：`Enter` 让**候选字上屏**，光标停在原要点内；**不得**新建要点、不得把要点拆成两条。
- 第 3 步：**不弹**「已保存」toast（组合态快捷键被吞）。
- 第 4 步：**不新增**要点副本。

**FAIL 典型表现**：候选还在浮动条上时按 Enter，结果要点被拆成两个空行——这是 `isComposingKey` 守卫失效。

**取证**：录屏 10 秒（最可靠）；或截图「按 Enter 前后的要点数对比」。

## 2. 关闭保护：手动模式三键框（丢数据风险）

**前提**：真窗、已激活、在编辑器内。

**步骤**
1. 点标题栏齿轮（`设置`）→ 左侧切到 **`通用`** → 分段控件点 **`手动`**。
2. 关掉设置（点遮罩或按 `Esc`）。
3. 状态栏确认已变为红点 + `手动保存 · 未保存`（改一个字之后）。
4. 随便改一个字。
5. 点标题栏最右 **✕**（`关闭`）。
6. 在弹窗里先点 **`取消`**。
7. 再点 ✕，这次点 **`不保存`**。

**判定**
- 第 5 步：必须出现对话框，标题 **`关闭前确认`**，正文 **`你有尚未保存的更改。`**，三个按钮 **`保存并关闭` / `不保存` / `取消`**。
- 第 6 步：窗口**仍在**，且刚改的那个字**还在**（未丢）。
- 第 7 步：窗口关闭；重开（`pnpm dev:kill` → `pnpm tauri:dev`）后那个字**不在**（因为选了不保存）。

**FAIL 典型表现**：点 ✕ 直接关窗，没有任何提示 → `dirty` 被 `flushPending` 覆盖（#110 的老缺陷回归）。

**取证**：截图弹窗（含三个按钮）；重开后的编辑器截图。

## 3. 窗口形态（#116 最小尺寸 + #112 圆角/直角）

**前提**：真窗、已激活、窗口为 1280×800。

**步骤**
1. 把鼠标放到窗口**右边缘**，向左拖。
2. 继续拖，直到拖不动为止；读窗口宽度。
3. 点标题栏 **`最大化`** 按钮。
4. 再点 **`向下还原`**。
5. `pnpm dev:kill`，然后清掉激活记忆再启动：启动进设置 → `激活管理` → 点 **`重置激活（清除本机记忆）`**，然后重启应用。

**判定**
- 第 2 步：窗口应能收到 **960×640**（不再是 1152×720 就卡住）。用 Win+← 分屏或截图后量像素均可。
- 第 3 步：最大化后**四角应为直角**（透明圆角被取消）。
- 第 4 步：还原后**四角恢复圆角**（`.shell` 10px）。
- 第 5 步：未激活启动时窗口是 **420×380 小窗**，且**无黑边**（整窗铺面板色）、有圆角、自带最小化与关闭按钮、可拖动。

**取证**：四张截图（960 宽 / 最大化角 / 还原角 / 420×380 门）。

## 4. 持久化：关窗重开数据仍在

**前提**：真窗、已激活、编辑器内。

**步骤**
1. 在任一要点末尾追加一个**独特字符串**，例如 `ACCEPT-TEST-20261113`。
2. 等 2 秒（自动保存防抖）。
3. 状态栏应显示 `自动保存 · 已保存`。
4. 关窗（点 ✕）。
5. 重开 `pnpm tauri:dev`，进入编辑器。

**判定**
- 重开后那段文字**仍在**。
- dev 构建的数据库文件在 `%APPDATA%\com.fairlens.desktop\fairlens_dev.db`（release 构建是 `fairlens.db`）。用任意 SQLite 客户端验证：

```sql
select id, title, updated_at from resumes order by updated_at desc;
select key, value_json from settings;
select substr(doc_json, 1, 200) from resumes order by updated_at desc limit 1;
```

- `resumes` 行数 ≥ 1；`settings` 里应有 `license`（激活记忆）与 `autosave`。
- 应有**五张表**：`resumes` / `resume_snapshots` / `review_sessions` / `ai_patch_log` / `settings`（`db.rs` 迁移 v1 建齐）。

**取证**：`doc_json` 里能搜到 `ACCEPT-TEST-20261113` 即铁证（截图 SQL 结果）。

## 5. 快照全流程（保存 → 对比 → 回滚）

**前提**：真窗、编辑器内。

**步骤**
1. 按 `Ctrl+K` 打开命令面板 → 输入 `快照` → 选 **`保存快照`** → toast 应显示 `快照已保存`。
2. 改一处内容（比如删掉一个要点里的半句）。
3. 再 `Ctrl+K` → 输入 `回滚` → 选 **`回滚到快照…`**，打开快照对话框。
4. 左侧列表选中刚才那条快照。
5. 读 diff 区。
6. 点 **`回滚到此`**。

**判定**
- 第 3 步：对话框标题 **`快照`**；未选中快照时显示 `暂无快照——编辑一段时间后存一个版本点吧` 或列表。
- 第 5 步：应显示 `新增 {{n}} · 修改 {{n}} · 删除 {{n}}` 统计与 **`块级差异（点击项定位）`** 列表，被改的那条标 **`修改`**；左栏标题 `快照版本`、右栏 `当前版本`。
- 第 6 步：toast `已回滚到所选快照`，且第 2 步删掉的内容**回来了**。
- 回滚后 `Ctrl+Z` 不应把回滚自身撤销掉（回滚是版本级操作）。

**取证**：diff 区截图（要看到「修改」标记）+ 回滚后内容截图。

## 6. 链接：Ctrl+点击真的能开浏览器

**前提**：真窗、编辑器内有可选中文字。

**步骤**
1. 选中一段文字。
2. 按 `Ctrl+K` → 工具条应出现输入框（默认 `https://`）→ 输入 `github.com/lisiyuan` 之类的合法地址 → 回车。
3. 按住 `Ctrl`，鼠标左键点这段链接文字。
4. 再选中另一段文字，`Ctrl+K`，输入 `ftp://example.com`，回车。

**判定**
- 第 2 步：文字变成链接样式（带下划线）。
- 第 3 步：**系统默认浏览器打开该地址**。若失败应弹 toast `打开链接失败：请检查系统默认浏览器设置`（不是静默）。
- 第 4 步：`ftp://` 应被白名单拒绝——链接**不被应用**（或应用后点击无反应）。

**已知限制**：完整键组合（Ctrl+按住+点击）此前用 CDP 与合成 MouseEvent 都无法还原，所以这一条只能人工。`opener.open_url` 本身已 CDP 实测成功（#114）。

**取证**：浏览器打开后的截图 + 任务栏出现浏览器进程。

## 7. 粘贴与结构化拦截（m1.4 尾项）

**前提**：真窗、编辑器内、光标在某个要点里。

**步骤**
1. 从浏览器复制一段**带加粗/链接的**富文本（例如任意新闻段落含链接），`Ctrl+V` 粘贴。
2. 观察粘贴点附近是否出现气泡；点 **`仅文本`**。
3. 复制一段超过 300 字的长文，`Ctrl+V`。
4. 复制一张图片（截图），`Ctrl+V`。
5. 选中一段带格式的文字，按 `Ctrl+Shift+V`。
6. 把某个分区填到条目上限（教育 4 / 实习 8 / 项目 6），**真窗实际点击条目头 `⋯ → 复制条目`**；再分别从右键、命令面板/Ctrl+D 退化路径触发复制。

**判定**
- 第 2 步：气泡有 **`保留格式`** 与 **`仅文本`**（后者带 `Ctrl+Shift+V` 提示）；点 `仅文本` 后**原地替换**为纯文字（加粗和链接消失）。
- 第 3 步：**插入前**弹选择（贴到当前简历 / 导入为新简历 / 取消）；选「贴到当前简历」后才插入并出现粘贴气泡；选「导入为新简历」当前文档不变并预填该次文本（m1.7 接通后）。
- 第 4 步：toast **`已忽略 1 张图片`**（或 N 张）。
- 第 5 步：粘贴结果为纯文本，**无任何加粗/链接**。
- 第 6 步：**所有复制入口**都弹同一确认「已到建议上限：已有 8 条，建议上限 8 条……仍然复制」；取消不新增，确认后**新增**副本（软上限不阻断）。

**取证**：6 张截图各一（气泡、长文提示（改为插入前选择）、图片 toast、纯文本结果、上限确认框）。

## 11. 反馈六项（2026-11-13，#120–#123）

**前提**：真窗、编辑器内。这六条是用户真机报障的回归验收，**每条都要按顺序做一遍**。

### 11.1 删掉新要点后不再弹三键框（#120）
**步骤**
1. 设置→`通用`→切 `手动`。
2. 在任一要点末尾按 `Enter` 新建一条要点（点什么也不写）。
3. 立刻按 `Backspace`（或空要点上 `Enter`）把它删掉，让内容回到刚打开时原样。
4. 点标题栏 ✕。

**判定**：**不弹**「关闭前确认」，窗口直接关（内容与基线相同 → dirty=false）。
**FAIL 表现**：仍弹三键框 = 脏标记又变回闩锁。
**取证**：无弹窗截图。

### 11.2 粘贴段落可点可存（#120）
**步骤**
1. 从浏览器复制**两段以上**的文字（带 `www` 段的富文本）。
2. 在要点里 `Ctrl+V`。
3. 鼠标点粘贴进来的**第二段**中间。
4. 关窗重开。

**判定**
- 2 段变成**两条要点**（各有圆点），不是一段裸段落；
- 第 3 步鼠标能**直接落光标**进该段（不再在它前面冒出新要点）；
- 第 4 步重开后文字**仍在**（旧实现会在保存时静默丢弃）。
**取证**：粘贴后截图 + 重开后截图。

### 11.3 长文 Ctrl+V 弹提示（#120）
**步骤**：复制 >300 字的富文本，在要点里 `Ctrl+V`。

**判定**：弹 **`内容较长，建议走导入向导以保留层级`**（旧实现只在 Ctrl+Shift+V 时弹）。
**取证**：toast 截图。

### 11.4 新增自定义分区（#121）
**步骤**
1. `Ctrl+K` → 输入 `分区` → 选 **`新增分区…`**。
2. 类型选 **`自定义`**，类型标识填 `self-eval`，标题填 `自我评价`，保存。
3. 在新分区里写两条要点。
4. 看左侧大纲。
5. 关窗重开。
6. `Ctrl+K` → `删除当前分区`（光标放到新分区里）。

**判定**
- 第 2 步：画布末尾出现新分区（标题「自我评价」+ 一条空要点）；大纲同步出现该分区；
- 第 4 步：大纲显示 **`自我评价`**（不是「基本信息」）；
- 第 5 步：重开后分区与要点都在；
- 第 6 步：弹出确认「删除分区「自我评价」？…」，确认后消失；**只剩一个分区时**应 toast `至少保留一个分区`。

### 11.5 页头加字段 + 日期填自由文本（#122）
**步骤**

3. 点某条目头笔形按钮（`编辑条目信息`）→ 起止时间填 **`大三 – 大四`**，保存。

5. 关窗重开。

**判定**

### 11.6 Tab 层级缩进（#123）

## 13. UIUX 契约轮（2026-11-17，#127）

### 13.1 结构编辑：从头写一份简历
**步骤**：进入编辑器 → 点任一分区标题右侧 hover 出现的「添加条目」→ 在新条目的「机构名称」处点开铅笔填写 → 在首条要点输入文字 → 重开编辑器（或重启应用）。

**判定**
- 分区标题 hover 出现「添加条目」；点击后出现「未命名条目」+ 一条空要点，光标在要点里；
- 条目头 hover 出现「⋯」，菜单含「复制条目 / 删除条目」；删除后 toast「已删除条目（Ctrl+Z 撤销）」，Ctrl+Z 能恢复；
- 新增条目里的文字**重开后还在**（这是 #127 修的数据丢失）；
- 空分区里点空白也能直接生成第一条条目。

### 13.2 空白点击全量
**步骤**：① 点两条要点之间的空白；② 点两条条目之间的空白；③ 点纸面灰色台面。

**判定**
- ① 在该位置插入一条新要点；② 在该位置插入一个新条目；③ **无反应**（不往任何分区插东西）。

### 13.3 结构锚点保护（防误删）
**步骤**：光标放到第一个分区标题行首按 Backspace；光标放到条目第一条要点行首按 Backspace；最后一条要点末尾按 Delete。

**判定**
- 页头（姓名/联系方式）**不消失**；条目头**不消失**；下一条目不会被并进来；
- 在第二条要点行首按 Backspace 仍能正常与上一条合并（保护只挡结构锚点）。

### 13.4 保存失败可见（关键项）
**步骤**：把简历库文件（或所在目录）设为只读后编辑内容等待自动保存；再点关闭窗口。

**判定**
- 不再 toast「已保存」，而是「保存失败——修改还没写入磁盘，请重试」；
- 状态栏「保存失败」右侧出现「重试」；
- 关闭窗口弹出「保存失败」保护框，含「重试保存并关闭 / 仍然关闭 / 取消」；点「取消」留在编辑器，内容还在。

### 13.5 浮层关闭与焦点
**步骤**：依次打开 设置 / 命令面板（Ctrl+K）/ 快照 / 删除分区确认 / 页头字段编辑；每次用 Esc 关、再重开用鼠标点灰底关。

**判定**
- 每一个都能 **Esc 关闭**、**点灰底关闭**（关闭保护与删除确认除外：点灰底不关、Esc=取消）；
- 关闭后**焦点回到编辑器**，直接打字能进正文；
- 在页头字段输入框里按 Ctrl+D **不会**复制条目；按 `?` 能打开快捷键速查。

### 13.6 示例与去假象
**步骤**：首次进入（示例简历）→ 看画布左上角 → 点胶囊里的「清空」→ 确认；再按 Ctrl+F 打开搜索条。

**判定**
- 画布左上角是**悬浮胶囊**「示例简历 · 清空」，不占布局高度（纸面位置不被下推）；搜索条打开后两者不重叠（胶囊在左、搜索在右）；

- 右栏默认关闭（可手动展开）；评估面板只显示「AI 评估尚未开放。」，没有分数/批注/第二句解释；

### 13.7 退出路径（#127 二次打磨）
**步骤**：① 打开「文件」菜单；② 手动模式下点标题栏 ✕；③ 按 Alt+F4；④ 打开 `?` 快捷键速查。

**判定**
- 文件菜单**没有**「关闭窗口/退出」项（避免被误读为关下拉）；
- ✕ 的悬停提示是「退出 FairLens（Alt+F4）」；点 ✕ 走同一套保存/关闭保护（手动有未保存时弹三键框）；
- Alt+F4 同样触发关闭保护，不绕过保存；
- 快捷键速查里有 Alt+F4 一行；
- 底栏右侧只有 **一个 `?` 键帽按钮**（无「快捷键」文字、无 Ctrl+K 长文案）；悬停提示「快捷键速查（?）」，点击能打开速查表。

### 13.8 箭头随悬停（#127 四次打磨）
**步骤**：鼠标停在正文（不碰顶栏），看模板按钮与导出按钮；再分别悬停两个按钮；最后用键盘 Tab 聚焦它们。

**判定**

- 大纲树的展开/折叠箭头、搜索上/下条、抽屉把手**仍然常显**（它们是结构/导航手势，不是下拉触发器）。

**判定**

## 14. m1.8 简历库（多份闭环，真窗）

> 前置：`pnpm dev:kill` → `pnpm tauri:dev`；本条全部涉及 SQLite 持久化，浏览器模式不适用。

### 14.0 库页视觉基线（对照预览）
**步骤**：打开 `docs/design-previews/fairlens-library-m18-preview.html` 作参照；真窗库页分别切浅色/深色，看模板卡、简历卡、空态、归档态。

**判定**
- 三张模板卡（108px，缩略图+名称+「点击新建」）与卡片网格、空态「模板卡居中放大」与预览一致；
- 归档卡**不整体变透明**：底色 tint + 虚线边框 + 「已归档」标签，文字清晰可读（对比度 ≥4.5:1；本轮实测 light 15.38 / dark 11.77）；
- 示例卡徽标在重命名后仍在；「清空为空白简历」后徽标与示例胶囊消失（身份已释放）。
- 删除示例时若身份键清理失败（可造只读库模拟），库页出现 **「重试清除示例标识」**；重试成功后提示消失，重启不再识别为示例。
- 清空示例时确认框在保存完成前**保持打开**（按钮禁用，Esc/点遮罩不关）；保存成功后才关闭并 toast「已清空」。保存期间无法返回库或选「不保存」。
- **快照阶段**（清空先存快照）按 `返回简历库` 或 **Alt+F4 / 任务栏关闭**：同样被阻塞，等快照与替换都完成后才按正常保护流程处理；不出现“返回后原简历被写空”。
- 造落盘失败后点 **取消**：画布、标题、磁盘内容与示例身份都回到清空前；再次保存写入的是原内容，不是空白。

**本轮挂起夹具（可复现）**：应用完成初始化后，用 Python 对 `fairlens_dev.db` 执行 `BEGIN EXCLUSIVE` 占住写锁（sqlx 默认 `busy_timeout=5s`，见 `sqlx-sqlite-0.8.6/src/options/mod.rs`），应用侧快照 INSERT 即真实阻塞；写释放文件后 `COMMIT` 继续。

### 14.1 多份持久化
**步骤**：首次进入库页 → 确认有「示例简历」卡 → 点模板卡「侧栏双栏」新建 → 卡片列表出现「我的简历」→ 打开它，写入一句独特内容 → 返回库 → 点「示例简历」打开 → 再返回 → 重启应用。

**判定**
- 模板卡新建的是**另一份**（示例卡仍在，两份标题/模板不同）；
- 重启后两份都在；「我的简历」有刚写的内容，「示例简历」内容未被覆盖。

### 14.2 切换保护
**步骤**：设置→通用→切 `手动`；打开「我的简历」改一个字；点左上 `返回简历库` → 先点 `取消`；再返回 → 点 `不保存`；重新打开「我的简历」。

**判定**
- 第一次返回弹 `关闭前确认`，点取消后仍停在编辑器且刚改的字还在；

**步骤**：真窗拖入 DOCX/PDF；`pnpm dev` 用文件选择器；真窗拖动大纲节点。

**判定**
- 真窗拖入有可见投放态，松手进入解析；大纲 dnd-kit 拖拽未被文件拖放开关破坏；
- 浏览器模式不显示假拖入，文件选择器走同一解析管线。

## 16. m1.9 成品分页视图（单页翻页 + 真实分页，真窗）

> 前置：`pnpm dev:kill` → `pnpm tauri:dev`；预览见 `docs/design-previews/fairlens-paged-view-m19-preview.html`。分页按模板实际排版测量，不按固定高度切。

### 16.1 单页翻页与缩放
**步骤**：打开一份 2 页简历 → 翻页到末页再返回；切换「整页 / 适应宽度」；调整缩放 30%/100%/150%；在 960×640 窗口重开。

**判定**
- 一次只显示一张 A4；`‹ 上一页 / 1 / N / 下一页 ›` 可用，首末页按钮正确禁用；
- 默认「整页」让整页完整可见（960×640 下缩到 30–40% 也应整页可见）；「适应宽度」给出可读字号并允许页内纵向滚动；
- **宽度模式（960×640，120%）纸张左右两侧都可见，不得裁掉左缘**；放大后翻页按钮仍可见可操作；缩放只改变查看，不改变页数与断点。

### 16.2 页数按模板排版计算
**步骤**：同一文档切换三套模板与两档密度。

**判定**
- 页数随模板/密度变化（记录切换前后页数）；
- **在第 3 页切到紧凑密度（页数变少）后，纸面必须有内容，不得出现空白页**；能定位原内容时保留阅读位置，否则落到仍存在的最后一页；
- 不出现按固定高度切出的空白/截断页。

### 16.3 条目跨页与续页小标题
**步骤**：造一段跨页的长经历（多要点）并翻到两页交界；再插入一条本身超过一页的超长要点。

**判定**
- 条目在**要点边界**分页，普通单条要点不被拆开；续页顶部有 `机构 · 职位（续）`；
- **超长单条要点按行拆成续段（`↳`）**，数据仍是一条要点；每页内容不超过 A4 安全高度（含续页小标题）；
- **单分区单条目、首条就是超长要点时，分区标题不得独占一页**（与页头/条目头/首段同页）；
- 跨页前后内容不丢，顺序正确。

### 16.4 标题不落单
**步骤**：调整内容让分区标题刚好落在页底。

**判定**
- 标题与首个内容一起移到下一页，不在页底单独出现。

### 16.5 编辑后重排
**步骤**：在分页视图内加/删要点与条目、切换模板与密度，观察页数。

**判定**
- 每次变化后页数与断点更新；编辑焦点/内容不因重排丢失；
- 加内容后 `原文件 N 页 → 排版后 M 页` 同步更新。

### 16.6 疑点标记与跳转
**步骤**：导入一份带未归类/低置信的简历 → 进入成品视图 → 点顶部「N 处待确认」；另造一份“原文件 2 页、仅提取 1 页、第 2 页无文字且无其他疑点”的草稿。

**判定**
- 疑点对应页有**纸外挂标**，点击跳页并高亮对应内容；
- **无文字源页没有对应纸面单元时，「待确认」入口仍可见**，点击明确提示“原文件第 N 页无文字，需回源检查”，不当作已解决；
- **计数与导入检查页一致（按组）：样例「3 块待整理 + 1 页未提取」两处都显示 2 处，明细见 tooltip/title（「待整理 3 块 · 未提取 1 页」）**；
- 挂标不进入导出（PDF 不含标记/徽标）。

### 16.7 原文件页数 vs 排版页数
**步骤**：导入原文件 2 页的 PDF → 看顶部页数口径。

**判定**
- 同时显示 `原文件 2 页` 与 `排版后 N 页`，不暗示还原原版式；
- 原文件页数来自解析报告，不因排版变化。

### 16.8 屏幕 = PDF
**步骤**：分页视图显示 3 页 → 导出 PDF → 用查看器核对页数与断点。

**判定**
- PDF 页数与屏幕一致；跨页条目/续页小标题位置一致；
- PDF 不含翻页 chrome、缩放、疑点挂标。

### 16.9 性能与边界
**步骤**：30 页长文档翻页、连续编辑触发重排；空文档/单页文档。

**判定**
- 翻页无明显卡顿；重排不阻塞输入（目标值实现时定）；
- 空文档/单页不报错，页码显示 `1 / 1`。

### 16.10 导入直达与内容一致
**步骤**：粘贴含姓名、附加信息、未归类块和来源页数的内容 → 导入 → 进入分页视图。

**判定**
- 不出现独立“完成页”；创建成功后直接打开成品视图；
- **成品视图显示同一份草稿：姓名（检查页改名后的最终值）、附加信息、待整理块都能在纸面找到**；
- **在检查页清空姓名后导入：成品页头不得恢复解析时的旧姓名**（姓名为空时横幅明确提示“导出前会拦截”）；
- 顶部同时显示原文件页数/提取页数/排版页数，疑点数量与导入检查稿一致；
- 不强制逐页确认；需检查时从顶部入口回到疑点。
