## 实现要点（2026-11-05 预览纸面结构回填）
- **NodeView（#117）**：`nodeviews/PageHeaderView`（姓名/意向/联系方式链接化 + MetaDialog）、`EntryHeaderView`（org/role/date 三段 + 日期区间解析）、`BasicFieldView`（NodeViewContent 值编辑，label/href attrs）、`SkillGroupView`（items hardBreak）、`PhotoSlotView`（虚线占位）；`MetaDialog` 通用弹层（Esc/遮罩取消、Enter 保存、必填/日期校验、IME 守卫）。
- **布局坑**：React NodeView 外层 `.react-renderer` 会阻断 duo grid —— 用 `.fl-paper > .react-renderer.node-flPageHeader { display: contents; }` 让 `.fl-head` 直接参与 grid；页头跨两栏。
- **printCSS 样式落点**：`.fl-head`/`.fl-entry-head .row`/`.fl-basic-field`/`.fl-skill-group`/`.fl-photo-slot`/`li[data-type=fl-bullet]` 均在注入的模板 CSS 内（画布=导出同源）；编辑按钮 `.fl-edit-btn` 屏幕可见、`@media print` 隐藏。
- **真窗/浏览器冒烟**：三套模板切换、页头/条目头编辑、220/296 右栏雷达、outline 折叠、Plex Sans SC 字体均实测（详见 STATE 待人工项）。
- **#118 关联修复（2026-11-05）**：`CanvasEditor` 空白点击的 onText 选择器原写 `header[data-type="fl-section-header"]`，实际节点是 `<h3>` → 点击分区标题被误判为空白并 `preventDefault`；已补 `h3[data-type="fl-section-header"]`。BasicFieldView/SkillGroupView/PhotoSlotView 的 NodeView 补 `data-block-id`（大纲叶节点 `scrollTo` 依赖；renderHTML 已有但 React NodeView DOM 不会自动带）。

- **粘贴管线**：`paste-format.ts`（纯规则：换行归一/空行折叠/大段判定/表格逐单元格平铺/转义与 `<br>` 连接）+ `use-paste-normalization.ts`（DOM 解析 `buildPastePlan`、统一插入 `insertPastePlan`、剪贴板读取 `readClipboardPayload`）。事件粘贴 / 右键粘贴 / Ctrl+Shift+V 共用同一管线。
- **气泡**：`PasteBubble.tsx` + `paste-bubble.ts`（纯几何 clamp/翻转）；portal 到 body + fixed（画布 zoom transform 下绝对定位错算——#106 教训）；立即插入保留格式，4 秒内可转「仅文本」，超时/Esc/点外关闭=保留格式。
- **仅文本替换**：用原始 PM 事务 `replaceWith` + 显式无 mark 文本节点 + `setStoredMarks([])`；不能走 `insertContentAt`（会继承当前加粗/斜体 mark，实测）。
- **插入区间**：`insertPastePlan` 临时截获 pasteHTML 同步事务的 `ReplaceStep`（`from + slice.size`），不用 content.size 差值（mark 边界/替换选区时算偏，实测导致「仅文本」替换错位）。
- **结构 gating**：`entry-duplicate.ts` 纯函数（按 section.type 查 `manifest.sections[].maxEntries`，超限返回 limit；复制条目/要点换新 id）；EditorMockup 超限 toast `editor.structure.limitReached`。
- **IME**：`ime.ts` 判定（isComposing/keyCode 229）；接入全局快捷键、Tiptap BulletNode Enter/Shift-Enter（`view.composing`）、命令面板/快照标签/链接输入、右键菜单与设置窗 Esc。
- **链接白名单**：`link-policy.ts` 的 `isSafeHref`（URL 解析，仅 http/https/mailto）绑定 Link `isAllowedUri` + `shouldAutoLink`；此前该函数是死代码、库默认放行 ftp/tel/sms。
- **useEditor 闭包**：`handlePaste` 用 `useMemo` 保持稳定，动态文案走 `tRef`，避免 `useEditor` 创建时捕获旧闭包。
- **#114 点空白新增要点**：`blank-click.ts`（pickAppendTarget 纯函数，6 单测）+ `.fl-host` onMouseDownCapture：点条目/分区空白/纸面底部（位于最后要点之下）→ 目标条目末尾插入新 flBullet 并置光标；点文字不拦截；basic 区无条目不动作。
