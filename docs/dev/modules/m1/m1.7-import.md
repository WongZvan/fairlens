## 可判定验收（对应 acceptance/M1.md §15）

1. **来源与快速路径**：空内容不能继续（按钮禁用+就地提示，无底栏绕过）；拖入区键盘可达；干净解析摘要「无待处理内容」→「导入并打开」≤2 次点击。
2. **条件检查**：疑点摘要「有 N 处需要检查」，问题项置顶、正常分区收起；左导航真实滚动定位；原文抽屉可对照/指派；分区与条目可改。
3. **DOCX**：分区/要点正确；表格逐格平铺；图片忽略提示。
4. **PDF**：文本型可导入；低置信标记可修正；扫描件明确报错不建记录；损坏/超 20MB 报错。
5. **未归类去向**：默认保留「待整理内容」；每块可指派/保留/显式丢弃；摘要列明；创建后可见可移动，保存不丢。
6. **超限跨层保留**：每条「显示/暂不显示」可切换；画布保留 hidden 可编辑；再次保存查库 `hidden:true` 仍在；重启/快照保留；PDF 不含、归档包含。
7. **导出前守关**：hidden/待整理内容非空 → 检查框逐条列影响；去处理/仍然导出；取消不导出。
8. **落库/失败/未完成态**：创建一次；失败可重试不谎报；关窗 CloseGuard；丢弃无半成品。
9. **入口/回退/拖拽**：真窗拖入；浏览器文件选择器同一管线；大纲 dnd-kit 正常。
10. **去导入**：气泡预填文本；完成后打开新简历，原文档不变。
