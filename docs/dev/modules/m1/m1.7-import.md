## 可判定验收（对应 acceptance/M1.md §15）

1. **来源与快速路径**：空内容不能继续；拖入区键盘可达；干净解析摘要「文件文字已提取 N/N 页 · 未发现需确认项，建议打开后快速检查」→「导入并打开」≤2 次点击。
2. **两段式检查**：有未归类/缺页/低置信时只展开问题项；问题项可跳转；分区与条目/要点可编辑且不会复位；界面无内部类型标识。
3. **DOCX**：分区/要点正确；表格逐格平铺；图片明确提示「图中文字不会导入」。
4. **PDF**：文本型可导入；**逐页**标出无文本页/低置信；扫描件明确报错不建记录；损坏/超 20MB 报错。
5. **原文对照**：抽屉展示不可变提取块（页码/位置 + 去向）；每块都有去向；指派/丢弃后去向同步更新。
6. **待整理内容**：真实分区，画布与 PDF/Word 都包含；导入摘要写明「会随简历一起导出」；指派后文字真实出现在目标分区；保存不丢。
7. **篇幅软上限**：9 条经历全部渲染并进入 PDF；仅提示「建议上限 8 条，可能偏长」；字数/AI/搜索/大纲都包含全部条目（无隐藏字段）。
8. **导出前守关**：待整理内容非空 → 提示「尚不可交付：PDF 会包含 N 块待整理内容」；「仍然导出」结果与纸面一致；归档不弹遗漏警告。
9. **落库/失败/未完成态**：创建一次；失败可重试不谎报；关窗 CloseGuard；丢弃无半成品。
10. **粘贴前选择**：大段粘贴先弹选择；「导入为新简历」当前文档不变并预填文本；「贴到当前简历」走原管线；取消不插入。
11. **入口/回退/拖拽**：真窗拖入；浏览器文件选择器同一管线；大纲 dnd-kit 正常。
