## 可判定验收（对应 acceptance/M1.md §15）

1. **粘贴导入**：库页点导入 → 粘贴含「教育经历/实习经历/技能」的文本 → 确认步识别出分区与条目 → 创建后打开编辑器，内容进入画布。
2. **DOCX**：导入一份含标题、要点、表格的 DOCX → 分区/要点正确；表格逐格平铺不丢字；图片提示忽略。
3. **PDF**：文本型 PDF 可导入；扫描件/无文本层显示明确错误并建议 DOCX/粘贴，不产生记录。
4. **启发式修正**：错误分区的块可从「未归类池」指派；分区标题/类型可改；改动即时反映在左侧导航。
5. **溢出**：条目超当前模板 maxEntries → 标黄并说明「保存在数据里，不显示不导出」；勾选条目排前；切换模板后渲染数量随之变化。
6. **落库**：创建后库页出现新卡片；重启仍在；原文档（若从编辑器进入）未被修改。
7. **失败可见**：造写入失败 → 完成步显示错误、可重试；不出现「已导入」谎报；不产生半成品记录。
8. **未完成态**：向导进行中点关窗 → CloseGuard 列出「导入未完成」；选继续编辑留在向导；丢弃后草稿清空。
9. **入口回退**：浏览器模式用文件选择器走同一解析管线；拖入区在无 Tauri 时不假装可用。
10. **去导入**：编辑器大段粘贴气泡点「去导入」→ 向导预填该次文本；完成后打开新简历，当前文档不变。
