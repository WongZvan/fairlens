## 实现要点（实录）
- 关键文件：`editor/{command-registry,shortcuts,FloatingToolbar}.ts(x)`、`editor-mockup/{OutlineTreeLive,CommandPalette}.tsx`
- BubbleMenu v3 坑：移到 `@tiptap/react/menus` 子路径（floating-ui 可选依赖）；props 从 tippyOptions 改 options（FloatingUI）；shouldShow 全签名
- **Ctrl+点击跳转（用户直报）**：Link `openOnClick:false` 下需自建 click 插件；`linkMark.extend()` 内的 handleClick 被 Link 内部处理吞掉（实测）→ 改顶层独立扩展 `linkClickPlugin`（PM `someProp` 语义验证 handled=true）；系统打开=openExternal 封装（Tauri opener 插件声明先行/web 降级 window.open，函数链实测）；**真键组合验证受自动化工具限制（cua.keypress+click 组合与合成 MouseEvent 均无法完整还原系统 Ctrl+click），需人工验收**
- **window.prompt 被吞（链接挂不上根因，用户直报）**：Tauri 无边框窗/IAB 环境 prompt 静默返回 null → Tiptap 链路本身全通（编程 setLink 实测 a[href] 生成）。修复=应用内行内输入气泡（Enter/✓ 确认，Esc/✕ 取消，scheme 白名单保留）。**教训：浏览器阻塞式对话框（prompt/alert/confirm）在桌面 shell 下一律不可用，输入一律做应用内 UI**
- **剪贴板往返断裂修复（追溯 m1.3）**：三节点 parseHTML 选择器反引号 → PM 复制→粘贴解析失败（用户精准复现）；回归=合成 copy 捕获 HTML+合成 paste 贴回，bullets 4→8 全量落位
- 撤销重做：CanvasEditor onReady 暴露 EditorApi（chain undo/redo）
- **Enter/Shift+Enter 键位补全（用户直报）**：Enter 在 bullet=同 entry 内新起一条 bullet（nanoid 新块）；Shift+Enter=hardBreak 软换行（runs 序列化含换行往返）；权限矩阵补注（内容结构，非格式）
