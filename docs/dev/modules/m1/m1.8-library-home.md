## 可判定验收（替换原来的“单测/E2E 绿”一句话）

1. **新建第二份**：首启有「示例简历」卡；点模板卡「侧栏双栏」→ 新增「我的简历」卡，示例仍在；打开它 → 画布 `data-template="tpl-duo"`，内容为空（不是示例内容）。
2. **切换**：返回库 → 打开另一份 → 标题/模板/内容对应该卡，不串数据。
3. **切换保护**：手动模式改一个字 → 返回库 → 弹「保存/不保存/取消」；点取消留在编辑器；点不保存回库且另一份内容未变。
4. **重命名**：卡片 ⋯ → 重命名 → 保存后卡片标题与重开后一致（真窗含 SQLite）。
5. **归档**：⋯ → 归档 → 卡片置灰且默认不显示；开「显示归档」可见；取消归档后恢复。**全部归档时**提示「没有可显示的简历」并指向「显示归档」，不得显示「还没有简历」；顶部显示 `0 份简历 · N 份已归档`。
6. **删除**：⋯ → 删除 → 确认框列出快照数并建议归档；确认后卡片消失；SQLite 侧删除**前**用夹具让 `resume_snapshots` / `review_sessions` / `ai_patch_log` 各存在属于该简历的记录，删除后三表均清零（内存路径验快照清零）；删光后进入空态（导入区禁用、不可点）。
7. **未开放能力**：导入区置灰且无可点按钮；备份与恢复显示「未开放」；卡片无评估徽章。
8. **删光后重启**：删掉全部简历 → 重启应用 → **仍是空态**（`sampleSeeded` 已置真，不再播种示例）。
9. **旧库升级不重复示例**：预置一个「已有简历、无 `sampleSeeded` 标记」的库 → 启动 → 仍只有那一份，**不新增示例**；标记被补为真；再重启仍只有一份。

## 实现要点（开发中回填：关键文件/接口/坑）

- **端口**：`packages/core/src/persistence-port.ts` 新增 `ResumeMeta`（含 `templateId`/`snapshotCount`）；`listResumeMetas` 返回全部状态。SQL 用 `template_id` + 快照数子查询，memory 同步。
- **迁移**：`db.rs` v2 `ai_patch_log_fk_cascade` 重建表补 FK；sqlx 0.8.6 默认 `foreign_keys=ON`，`tauri-sql-adapter` 加载时断言 `PRAGMA foreign_keys=1`；`deleteResume` 仍是单条 DELETE。
- **状态**：`stores/library.ts`（三态播种/新建/重命名/软归档/删除）；`editor-doc.openCurrent()` → `openResume(id)`，示例播种与“查不到就建”彻底移出编辑器。
- **视图**：`features/library/{LibraryView.tsx,library.css,library-view-model.ts}`；模板选项抽到 `features/templates/choices.ts`；卡片菜单复用 `app/dropdown.tsx`，删除确认复用 `app/ConfirmDialog.tsx`，重命名用 `app/Overlay.tsx`。
- **并发与失败（2026-11-23 codex 复核后补强）**：`editor-doc` 每份文档一个 session（row+controller），保存闭包绑定会话；`openSeq` 后发起的打开胜出，被超越返回 `superseded`。`library.init()` 单飞，写操作先 await；`initialized` 前模板卡禁用；**新建走串行链且每次读最新标题**（连续点击不重名）。`refreshInner` 不吞错且**串行执行**（旧查询不可能晚到覆盖、写后刷新不会被超越后静默成功）；写操作返回 `WriteOutcome`：`write-failed` / `refresh-failed` / **`cleanup-failed`**（分别提示、后者提供「重试清除示例标识」）。**清空示例的确认框在落盘完成前保持 pending**；`openResume`、`requestClose`（含 Alt+F4/任务栏关闭）都先 `waitForReplace()`——避免“清空→关窗/返回→不保存”与旧写入交错；保存失败回滚画布/标题/会话行；身份清理使用开始时的样例判断。旧库身份回填只尝试一次（`sampleIdentityMigrated`），候选读取失败不写标记。重命名/删除失败保留弹窗并显示错误（ConfirmDialog 支持 pending/error），归档失败 toast。示例身份用 `settings.sampleResumeId`：重命名保留、清空/删除释放、库页每次 refresh 重读；旧库回填需「唯一标题 + 文档与 sampleDoc 一致」（不误认同名用户简历）。
- **归档可读性**：去掉整卡 `opacity`，改底色 tint + 虚线边框；实测对比度 light **15.38** / dark **11.77**（opacity=1）。
- **坑**：①NodeView/按钮不用 `<button>` 嵌套交互控件（卡片整卡按钮 + 同级 ⋯）；②重命名/删除后重绘会替换触发元素，焦点按卡片 id 找回；③空态布局仅当 `metas.length===0`，全部归档时走“显示归档”提示；④浏览器内存适配器删除必须显式清快照，SQLite 靠级联——两条路径分别测；⑤清空示例后必须释放 sampleResumeId，且库页返回要 refresh 重读（否则徽标残留）。
- **验证**：**377 单测 / 50 文件**（并发 A/B 乱序、会话绑定、init 串行、旧库身份一次性回填/读取失败重试/不误认、清空同步与删键失败、写入/刷新失败区分、刷新串行、身份清理失败重试、连续新建去重）；**E2E 9 条**（smoke + first-use 2 + library 6）；`cargo test db::tests` 通过。真窗 §14 待人工。
