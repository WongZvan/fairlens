## 可判定验收（替换原来的“单测/E2E 绿”一句话）

1. **新建第二份**：首启有「示例简历」卡；点模板卡「侧栏双栏」→ 新增「我的简历」卡，示例仍在；打开它 → 画布 `data-template="tpl-duo"`，内容为空（不是示例内容）。
2. **切换**：返回库 → 打开另一份 → 标题/模板/内容对应该卡，不串数据。
3. **切换保护**：手动模式改一个字 → 返回库 → 弹「保存/不保存/取消」；点取消留在编辑器；点不保存回库且另一份内容未变。
4. **重命名**：卡片 ⋯ → 重命名 → 保存后卡片标题与重开后一致（真窗含 SQLite）。
5. **归档**：⋯ → 归档 → 卡片置灰且默认不显示；开「显示归档」可见；取消归档后恢复。**全部归档时**提示「没有可显示的简历」并指向「显示归档」，不得显示「还没有简历」；顶部显示 `0 份简历 · N 份已归档`。
6. **删除**：⋯ → 删除 → 确认框列出快照数并建议归档；确认后卡片消失；SQLite 侧 `resume_snapshots` / `review_sessions` / `ai_patch_log` 三张子表按 `resume_id` 全部清零（内存路径验快照清零）；删光后进入空态（导入区禁用、不可点）。
7. **未开放能力**：导入区置灰且无可点按钮；备份与恢复显示「未开放」；卡片无评估徽章。
8. **删光后重启**：删掉全部简历 → 重启应用 → **仍是空态**（`sampleSeeded` 已置真，不再播种示例）。
