## 中（2 条）

2. **自然语言触发未声明**：命令集依赖用户记六条短语，间隔数周会忘，兜底"核对状态层"也需用户记得。→ 补声明："自然语言描述意图时 AI 应自动映射到对应命令例程——短语是快捷方式而非唯一入口"。
3. **AGENTS.md 副本静默过时**：G-D 只管规则回灌，不管"副本落后多少"。→ DOC-SPEC §B-6/§D 补：AGENTS.md 副本头部标注"复制自 <日期>版 SOP，校验以 ~/.agents/ 最新版为准"。

## 低（3 条）

4. **悬挂清账无 trace**：清账即删，历史悬挂处置无 trace。→ 补：清账时移入 `decisions/` 或 `notes/` 留一行记录。
5. **G 编号对 AI 的消费语义未定**：AI 读到"G-B"应该知道什么？→ 补：G 编号=指向章节的指针，AI 应读对应章节正文而非凭编号猜语义。
6. **先例引用对新项目是噪音**：SOP 多处引用"m1.5 修 m1.3"先例——新项目没有这些模块。→ SOP 头部注记"先例引用仅供理解规则出处，新项目按规则本身执行"。
